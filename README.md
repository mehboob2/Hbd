# Birthday Dreamland — 100-feature style experience 💙

A completely different birthday website concept: a personal mini-universe with a starry sky, mood themes, memory galaxy, flower garden, mini games, cake studio, wish wall, love letter, music and finale animation.

## Put these files in the same root folder
- index.html
- style.css
- script.js
- birthday.mp3
- rm1.jpg through rm10.jpg

Optional: add your own `happy.mp4` later if you want a video chapter. File names are case-sensitive on GitHub Pages.

## Run
Open `index.html`, or publish the folder using GitHub Pages. Tap Music once because mobile browsers often block autoplay.
